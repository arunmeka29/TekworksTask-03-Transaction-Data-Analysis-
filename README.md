# 📊 Sales Data Analysis

## Overview

This project analyzes sales transaction data to understand customer behavior, product performance, and sales trends.

## Objectives

* Study month-wise and quarter-wise sales trends
* Identify high and low performing product categories
* Analyze repeat customers
* Compare spending patterns across states and payment methods

## Tools Used

* Python
* Pandas
* Jupyter Notebook

## Conclusion

The analysis helps identify key sales trends and supports better business decisions related to marketing and inventory planning.
